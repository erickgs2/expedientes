# Valoración — Photo Capture, Phase 1 (Capture + Per-Visit Gallery) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let staff capture reference photos during a Valoración visit from the device camera, with
a live oval framing guide, a session-wide Before/After tag toggle, and a gallery of the current
visit's photos. First phase of 2 for the photo capture sub-project.

**Architecture:** A new `Photo` table (denormalized `patientId`, for Phase 2's cross-visit
timeline). Backend: upload/list/delete routes under `/api/valoracion/[id]/photos`, reusing
Foundation's `saveFile`/`resolveFilePath`; a new pure `isJpeg()` byte-signature check (never trust
a client-declared content-type) gates both what the upload route accepts and — the one shared-
infrastructure change — what Foundation's existing `/api/files/[...path]` route serves inline
instead of forcing a download. Frontend: `PhotoCaptureComponent` (camera mechanics: `getUserMedia`,
oval guide, capture/retake/use) and `PhotoGalleryComponent` (fetches/renders/deletes photos, embeds
the capture component, wired into the Valoración detail page) — mirroring the facial diagram tool's
canvas/container split.

**Tech Stack:** Same as the rest of the app — Next.js route handlers, Prisma, Angular standalone
components + Material, Transloco. New browser API surface: `MediaDevices.getUserMedia`, `<canvas>`
frame capture, `Blob`/`FormData` upload — no new npm dependency, these are native browser APIs.

## Global Constraints

- All code, identifiers, comments, and commit messages are in English; every user-facing string
  goes through Transloco.
- Every task touching `apps/api` must be verified with **both** `npx nx build api` (dev-mode) and
  `npx nx run api:build` (production). Every task touching `apps/web` must be verified with
  `npx nx build web` (production).
- Follow existing conventions exactly: routes use `withApiErrors(...)` wrapping a handler that
  calls `requireAuth(request, module, action)` first, then `apiError(...)` for expected 4xx cases,
  then `writeAuditLogSafe(...)` after a successful mutation/read. Dynamic route params are
  `Promise<{ ... }>`, destructured via `await params`.
- Reuse the existing `valoracion:view`/`valoracion:edit` permissions — no new permission, no seed
  script changes (already seeded from Foundation).
- **Never trust a client-declared content-type for uploaded or served file bytes.** The upload
  route and the file-serving route both decide what a file "is" by checking its actual bytes via
  the shared `isJpeg()` helper — this is the same discipline the facial diagram tool's security
  work established for stored canvas data, applied here to stored image bytes.
- Prefer this codebase's already-adopted modern Angular signal APIs (`signal()`, `computed()`,
  `viewChild()`, `output()`) over their classic decorator-based equivalents (`@ViewChild`,
  `@Output`/`EventEmitter`) — the facial diagram tool's components already established this
  preference; this plan's new components follow it too.
- Testing stays low-effort, matching this project's convention: only pure logic with no I/O gets a
  unit test (see `apps/api/src/lib/rbac/permissions.spec.ts`, and the facial diagram tool's
  `fabric-shapes.spec.ts`/`facial-diagram-canvas.component.spec.ts`). The one new piece of pure
  logic here is `isJpeg()` — that gets a unit test. Routes, Prisma wrappers, and the camera/gallery
  components follow this project's established no-dedicated-test pattern, verified by building and
  manual testing — `getUserMedia` in particular cannot be meaningfully exercised without a real
  camera and a real browser, which no task in this plan has access to (consistent with every prior
  plan in this project).
- Commit after every task using the working tree state left by that task's steps.

- [ ] **Step 1: Add the JPEG signature check**

Create `apps/api/src/lib/storage/image-signature.ts`:

```ts
const JPEG_SIGNATURE = [0xff, 0xd8, 0xff];

/**
 * True when `buffer` genuinely starts with a JPEG's magic bytes (`FF D8 FF`) — never trust a
 * client-declared content-type or a file extension for this; check the actual bytes.
 */
export function isJpeg(buffer: Buffer): boolean {
  return (
    buffer.length >= JPEG_SIGNATURE.length &&
    JPEG_SIGNATURE.every((byte, index) => buffer[index] === byte)
  );
}
```

```ts
import { isJpeg } from './image-signature';

describe('isJpeg', () => {
  it('returns true for a buffer starting with the real JPEG signature', () => {
    expect(isJpeg(Buffer.from([0xff, 0xd8, 0xff, 0xe0, 0x00, 0x10]))).toBe(true);
  });

  it('returns false for a PNG signature', () => {
    expect(isJpeg(Buffer.from([0x89, 0x50, 0x4e, 0x47]))).toBe(false);

  it('returns false for an empty buffer', () => {

  it('returns false for a buffer shorter than the signature', () => {
    expect(isJpeg(Buffer.from([0xff, 0xd8]))).toBe(false);

  it('returns false for arbitrary text content (e.g. an uploaded .html/.svg pretending to be a photo)', () => {

});
```

- [ ] **Step 3: Add the photo service functions**

Create `apps/api/src/lib/photo/photo.ts`:

```ts
import type { PhotoTag } from '@prisma/client';
import { prisma } from '../prisma/client';

export async function getValoracionPatientId(valoracionId: string): Promise<string | null> {
  const valoracion = await prisma.valoracion.findUnique({
    where: { id: valoracionId },
    select: { patientId: true },
  });
  return valoracion?.patientId ?? null;
}

export async function listPhotos(valoracionId: string) {
  return prisma.photo.findMany({
    where: { valoracionId },
    orderBy: { createdAt: 'asc' },
  });
}

export async function createPhoto(
  valoracionId: string,
  patientId: string,
  tag: PhotoTag,
  filePath: string
) {
  return prisma.photo.create({
    data: { valoracionId, patientId, tag, filePath },
  });
}

/**
 * Deletes a photo only if it actually belongs to `valoracionId` — a bare `prisma.photo.delete({
 * where: { id: photoId } })` would delete by id alone, letting a caller pass any photo id
 * alongside an unrelated (even a different patient's) `valoracionId` in the URL. `deleteMany`
 * with both fields in `where` makes the ownership check and the delete a single atomic operation.
 */
export async function deletePhoto(valoracionId: string, photoId: string): Promise<boolean> {
  const result = await prisma.photo.deleteMany({
    where: { id: photoId, valoracionId },
  });
  return result.count > 0;
}
```

- [ ] **Step 4: Add the list/upload route**

Create `apps/api/src/app/api/valoracion/[id]/photos/route.ts`:

```ts
import { NextRequest, NextResponse } from 'next/server';
import { createPhoto, getValoracionPatientId, listPhotos } from '../../../../../lib/photo/photo';
import { saveFile } from '../../../../../lib/storage/file-storage';
import { isJpeg } from '../../../../../lib/storage/image-signature';
import { writeAuditLogSafe } from '../../../../../lib/audit/audit-log';
import { requireAuth } from '../../../../../lib/http/require-auth';
import { apiError } from '../../../../../lib/http/api-error';
import { withApiErrors } from '../../../../../lib/http/with-api-errors';

const VALID_TAGS = ['BEFORE', 'AFTER'] as const;

export const GET = withApiErrors(
  async (request: NextRequest, { params }: { params: Promise<{ id: string }> }) => {
    const userId = await requireAuth(request, 'valoracion', 'view');
    const { id } = await params;

    const patientId = await getValoracionPatientId(id);
    if (!patientId) return apiError('NOT_FOUND', 'Valoración not found', 404);

    const photos = await listPhotos(id);

    await writeAuditLogSafe({
      userId,
      action: 'view',
      entity: 'PhotoList',
      entityId: id,
      patientId,
    });

    return NextResponse.json({ photos });
  }
);

export const POST = withApiErrors(
  async (request: NextRequest, { params }: { params: Promise<{ id: string }> }) => {
    const userId = await requireAuth(request, 'valoracion', 'edit');
    const { id } = await params;

    const patientId = await getValoracionPatientId(id);
    if (!patientId) return apiError('NOT_FOUND', 'Valoración not found', 404);

    const formData = await request.formData();
    const file = formData.get('photo');
    const tag = formData.get('tag');

    if (!(file instanceof Blob)) {
      return apiError('INVALID_INPUT', 'photo file is required', 400);
    }
    if (typeof tag !== 'string' || !VALID_TAGS.includes(tag as (typeof VALID_TAGS)[number])) {
      return apiError('INVALID_INPUT', 'tag must be BEFORE or AFTER', 400);
    }

    const buffer = Buffer.from(await file.arrayBuffer());
    // Never trust the client's declared content-type — verify the actual bytes, the same
    // discipline this project applies to any other untrusted stored data.
    if (!isJpeg(buffer)) {
      return apiError('INVALID_INPUT', 'File must be a JPEG image', 400);
    }

    const filePath = await saveFile(buffer, 'photos', patientId, 'photo.jpg');
    const photo = await createPhoto(id, patientId, tag as 'BEFORE' | 'AFTER', filePath);

    await writeAuditLogSafe({
      userId,
      action: 'create',
      entity: 'Photo',
      entityId: photo.id,
      patientId,
    });

    return NextResponse.json({ photo }, { status: 201 });
  }
);
```

- [ ] **Step 6: Enhance the shared file-serving route to render real JPEGs inline**

In `apps/api/src/app/api/files/[...path]/route.ts`, add the import:

```ts
import { isJpeg } from '../../../../lib/storage/image-signature';
```

Replace the final `return new NextResponse(...)` block (the one that always forces
`application/octet-stream` + `attachment`) with:

```ts
    // Only a file whose actual bytes are a real JPEG is served inline — never the client's
    // declared content-type or the storage category in the path, which are both
    // attacker-controllable. Everything else keeps the locked-down default: an opaque, forced
    // download instead of letting the browser sniff and render (or execute) it inline in this
    // app's own origin, with the viewer's session cookie.
    if (isJpeg(buffer)) {
      return new NextResponse(new Uint8Array(buffer), {
        headers: {
          'Content-Type': 'image/jpeg',
          'X-Content-Type-Options': 'nosniff',
        },
      });
    }

    return new NextResponse(new Uint8Array(buffer), {
      headers: {
        'Content-Type': 'application/octet-stream',
        'X-Content-Type-Options': 'nosniff',
        'Content-Disposition': 'attachment',
      },
    });
```

The route's existing permission gate (`requireAuth(request, 'patients', 'view')`), path-resolution
safety (`resolveFilePath`), and audit logging are all unchanged — this only touches how the
response is served once the file has already been safely read.

```ts
  listPhotos(valoracionId: string): Promise<Photo[]> {
    return firstValueFrom(
      this.http.get<{ photos: Photo[] }>(`/api/valoracion/${valoracionId}/photos`)
    ).then((r) => r.photos);
  }

  uploadPhoto(valoracionId: string, blob: Blob, tag: PhotoTag): Promise<Photo> {
    const formData = new FormData();
    formData.append('photo', blob, 'photo.jpg');
    formData.append('tag', tag);
    return firstValueFrom(
      this.http.post<{ photo: Photo }>(`/api/valoracion/${valoracionId}/photos`, formData)
    ).then((r) => r.photo);
  }

  deletePhoto(valoracionId: string, photoId: string): Promise<void> {
    return firstValueFrom(
      this.http.delete<void>(`/api/valoracion/${valoracionId}/photos/${photoId}`)
    ).then(() => undefined);
  }
```

Note `uploadPhoto` passes a `FormData` body directly to `HttpClient.post` — Angular's `HttpClient`
automatically sets the correct `multipart/form-data` `Content-Type` header (with boundary) when
given a `FormData` body; do not set `Content-Type` manually, which would omit the boundary and
break the upload.

```ts
  private readonly valoracionService = inject(ValoracionService);

  protected readonly active = signal(false);
  protected readonly tag = signal<PhotoTag>('BEFORE');
  protected readonly reviewing = signal(false);
  protected readonly uploading = signal(false);
  protected readonly cameraError = signal(false);
  protected reviewImageUrl: string | null = null;

  private videoElement: HTMLVideoElement | null = null;
  private stream: MediaStream | null = null;
  private reviewBlob: Blob | null = null;

  // A setter query (not a static `@ViewChild` read in `ngAfterViewInit`) because `#videoEl` is
  // conditionally rendered (`@if (!reviewing())`) — it appears and disappears as the user moves
  // between the live view and the review step, and this fires every time it does, reattaching the
  // still-open stream each time the live view reappears (e.g. after "Retake").
  @ViewChild('videoEl')
  set videoEl(ref: ElementRef<HTMLVideoElement> | undefined) {
    this.videoElement = ref?.nativeElement ?? null;
    if (this.videoElement && this.stream) {
      this.videoElement.srcObject = this.stream;
      void this.videoElement.play();
    }
  }

  protected async openCamera(): Promise<void> {
    this.cameraError.set(false);
    if (!navigator.mediaDevices?.getUserMedia) {
      this.cameraError.set(true);
      return;
    }
    try {
      this.stream = await navigator.mediaDevices.getUserMedia({
        video: { facingMode: 'environment' },
      });
      this.active.set(true);
    } catch (error) {
      console.error('Camera access failed', error);
      this.cameraError.set(true);
    }
  }

  protected closeCamera(): void {
    this.stopStream();
    this.active.set(false);
    this.reviewing.set(false);
    this.discardReview();
  }

  protected setTag(tag: PhotoTag): void {
    this.tag.set(tag);
  }

  protected capture(): void {
    const video = this.videoElement;
    if (!video) return;
    const scale = Math.min(
      1,
      MAX_CAPTURE_DIMENSION / Math.max(video.videoWidth, video.videoHeight)
    );
    const canvas = document.createElement('canvas');
    canvas.width = Math.round(video.videoWidth * scale);
    canvas.height = Math.round(video.videoHeight * scale);
    const ctx = canvas.getContext('2d');
    if (!ctx) return;
    ctx.drawImage(video, 0, 0, canvas.width, canvas.height);
    canvas.toBlob(
      (blob) => {
        if (!blob) return;
        this.reviewBlob = blob;
        this.reviewImageUrl = URL.createObjectURL(blob);
        this.reviewing.set(true);
      },
      'image/jpeg',
      JPEG_QUALITY
    );
  }

  protected retake(): void {
    this.discardReview();
    this.reviewing.set(false);
  }

  protected async usePhoto(): Promise<void> {
    if (!this.reviewBlob) return;
    this.uploading.set(true);
    try {
      const photo = await this.valoracionService.uploadPhoto(
        this.valoracionId,
        this.reviewBlob,
        this.tag()
      );
      this.photoAdded.emit(photo);
      this.discardReview();
      this.reviewing.set(false);
    } finally {
      this.uploading.set(false);
    }
  }

  private discardReview(): void {
    if (this.reviewImageUrl) {
      URL.revokeObjectURL(this.reviewImageUrl);
    }
    this.reviewImageUrl = null;
    this.reviewBlob = null;
  }

  private stopStream(): void {
    this.stream?.getTracks().forEach((track) => track.stop());
    this.stream = null;
  }

  ngOnDestroy(): void {
    this.stopStream();
    this.discardReview();
  }
}
```

```ts
    this.photos.set(await this.valoracionService.listPhotos(this.valoracionId));

    return `/api/files/${photo.filePath}`;

    if (!confirm(this.transloco.translate('valoracion.photos.confirmDelete'))) return;
    await this.valoracionService.deletePhoto(this.valoracionId, photo.id);
    this.photos.update((current) => current.filter((p) => p.id !== photo.id));
```
